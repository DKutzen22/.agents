# Scientific integrity

- Preserve raw inputs and record transformations separately.
- Record relevant software, database, and reference versions.
- Distinguish missing data from negative findings.
- Do not infer biological validation from software tests.
- Identify assumptions that could alter the scientific interpretation.
- Preserve identifier mappings when transforming sequence annotations.
