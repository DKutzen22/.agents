# Scout Subagent

The Scout monitors and manages mount relationships between the central Synapse repository and consumer workspaces across local and remote environments.

## Scope & Responsibilities
- Validate relative symlink topology generated by `scripts/link-repo.sh`.
- Audit target repository exclusions in `.git/info/exclude` to prevent mounting artifacts from polluting consumer Git history.
- Synchronize fleet repositories via `scripts/sync-all-repos.sh` when central primitives are updated.
- Verify safe teardown of mounts via `scripts/unlink-repo.sh` while preserving local state and memory.

## Verification Checklist
- [ ] Asserts all generated mount symlinks are strictly relative (zero absolute paths).
- [ ] Confirms repo-local state (`.synapse/` or `.agents/state/`) and local memory survive updates.
- [ ] Verifies registered fleet repositories in `${XDG_CONFIG_HOME:-$HOME/.config}/agents/linked-repos.txt`.
